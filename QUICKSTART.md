# Quick Start Guide

## Get Started in 3 Steps

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

The application will open at `http://localhost:3000`

### 3. Start Building Your CV!
1. Fill in your personal information
2. Add your work experience
3. Add education details
4. Add skills
5. Choose a template (Modern, Classic, or Creative)
6. Export to PDF

## Available Commands

| Command | Description |
|---------|-------------|
| `npm run dev` | Start development server |
| `npm run build` | Build for production |
| `npm run preview` | Preview production build |
| `npm run lint` | Run ESLint |

## First Time Usage Tips

### Personal Information
- Start by filling in your name, email, phone, and location
- Add your professional summary (this appears at the top of your CV)
- Optional: Add links to your website, LinkedIn, and GitHub

### Adding Sections
- Click the **"+"** button to add new entries for experience, education, projects, etc.
- Use the **edit** icon to modify existing entries
- Use the **delete** icon to remove entries

### Skills
- Choose category: Technical, Soft Skills, Languages, or Other
- Select proficiency level
- Add as many skills as you need

### Templates
- **Modern**: Best for tech and creative roles
- **Classic**: Perfect for corporate and traditional industries  
- **Creative**: Great for designers and creative professionals

### Export Tips
- Fill in all sections before exporting
- Review the preview to ensure everything looks good
- Click "Export to PDF" to download your CV
- The filename will be based on your name

## Data Storage

Your CV data is automatically saved in your browser's local storage. This means:
- ✅ Your progress is saved automatically
- ✅ You can close the browser and come back later
- ✅ No account or internet connection needed
- ⚠️ Clearing browser data will delete your CV
- ⚠️ Data is not synced across devices

**Tip**: Export your CV to PDF regularly to back up your work!

## Keyboard Shortcuts

- **Enter** in skill name field: Add skill
- **Enter** in language field: Add language
- **Enter** in technology field (Projects): Add technology

## Troubleshooting

### PDF export not working?
- Make sure you have filled in at least the personal information
- Try using Chrome or Edge browser
- Disable browser extensions that might interfere

### Data not saving?
- Check if browser storage is enabled
- Make sure you're not in private/incognito mode

### Preview not updating?
- Refresh the page
- Check browser console for errors
