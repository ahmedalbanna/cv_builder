## 🚀 How to Use

### **Switch Language:**
1. Click the language button in the header (العربية / English)
2. Application instantly switches to selected language
3. Layout automatically adjusts (RTL for Arabic, LTR for English)
4. All text updates in real-time

### **Create CV in Arabic:**
1. Click العربية button
2. Click "إنشاء سيرة ذاتية جديدة" (Create New CV)
3. Fill in form - all labels are in Arabic
4. Preview CV - all text in Arabic
5. Export PDF - Arabic text preserved

### **Create CV in English:**
1. Click English button
2. Click "Create New CV"
3. Fill in form - all labels in English
4. Preview CV - all text in English
5. Export PDF - English text preserved
