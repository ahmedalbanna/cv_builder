## 📐 Template Specifications

### Modern ✨
```
Colors:     Teal (#14b8a6), White
Layout:     Two columns (sidebar + main)
Typography: Inter, Sans-serif
Sections:   All sections supported
Special:    Colorful section headers
Print:      A4 optimized
```

### Classic 📋
```
Colors:     Black, White, Gray
Layout:     Single column, traditional
Typography: Georgia, Serif
Sections:   All sections supported
Special:    Formal structure
Print:      A4 optimized
```

### Creative 🎨
```
Colors:     Purple (#8b5cf6), White
Layout:     Two columns (dark sidebar)
Typography: Inter, Sans-serif
Sections:   All sections supported
Special:    Icon-based headers, Timeline
Print:      A4 optimized
```

### Minimalist ⚪
```
Colors:     Grayscale only
Layout:     Single column, lots of whitespace
Typography: Inter, Light weight
Sections:   All sections supported
Special:    Bullet separators (•), Uppercase headers
Print:      A4 optimized
```

### Professional 💼
```
Colors:     Blue (#1e40af), White
Layout:     Single column, timeline style
Typography: Georgia, Serif
Sections:   All sections supported
Special:    Gradient header, Timeline dots
Print:      A4 optimized
```

### Elegant 👔
```
Colors:     Black, White, Gray
Layout:     Centered, symmetric
Typography: Georgia, Serif with italics
Sections:   All sections supported
Special:    Centered name, Quote-style summary
Print:      A4 optimized
```

### Tech 💻
```
Colors:     Green (#22c55e), Slate (#0f172a)
Layout:     Single column, terminal style
Typography: Monospace (Courier, Monaco)
Sections:   All sections supported
Special:    HTML tags, Code comments, Terminal prompt
Print:      A4 optimized (dark theme)
```

## 🎨 Visual Style Guide

### Header Styles

**Modern**: Colorful gradient background
**Classic**: Simple centered text
**Creative**: Purple sidebar with photo
**Minimalist**: Ultra-simple with dots
**Professional**: Bold blue gradient
**Elegant**: Centered with borders
**Tech**: Terminal window style

### Section Dividers

**Modern**: Colored headers with icons
**Classic**: Simple underlines
**Creative**: Icon-based with colors
**Minimalist**: Uppercase with spacing
**Professional**: Bold with double border
**Elegant**: Centered with border-bottom
**Tech**: HTML/XML tags (`<section>`)

### Typography Hierarchy

**Modern**: Bold sans → Regular → Small
**Classic**: Serif large → Medium → Small
**Creative**: Sans bold → Color → Small
**Minimalist**: Light → Medium → Minimal
**Professional**: Serif bold → Semibold → Small
**Elegant**: Light → Italic → Refined
**Tech**: Mono → Green accents → Comments

## 💡 Tips for Choosing

### ✅ Do:
- Consider your target industry
- Match your personal brand
- Think about where you're applying
- Test multiple templates
- Get feedback from others

### ❌ Don't:
- Choose based only on looks
- Ignore industry norms
- Over-design for conservative fields
- Under-design for creative roles
- Forget about ATS compatibility

---

## 🔄 Switching Templates

**All templates use the same data!**

1. Fill in your information once
2. Click template selector
3. Preview different styles instantly
4. No data loss when switching
5. Export your favorite

**Pro Tip**: Create PDF versions of multiple templates and choose the best one for each application!
