## Template Switching

All templates use the same data structure, so you can:
1. Fill in your information once
2. Switch between templates instantly
3. Compare different looks
4. Export your favorite version

**Your data is automatically saved** and persists across template changes!

## Technical Details

### Built With:
- **React** + **TypeScript** for type safety
- **Tailwind CSS** for responsive styling
- **Lucide React** for icons
- **jsPDF** + **html2canvas** for PDF export

### Print Optimization:
All templates include:
- Print-friendly layouts
- Proper page breaks
- No-print classes for UI elements
- A4 dimensions (210mm × 297mm)

### Responsive Design:
- Mobile preview available
- Desktop-optimized layouts
- Print-optimized for PDF export
